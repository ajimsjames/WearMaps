# WearMaps

WearMaps is a lightweight offline/online map viewer and location telemetry app for Wear OS.

## Features
- Real-time GPS coordinates, velocity, and bearing indicators\n- Offline tile caching support for mapping without active network connection\n- Round screen bezel optimizations

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.

## Technical Details
- **Namespace**: `com.ajimsjames.wearmaps`
- **Version**: `2.1.0`
- **Target OS**: Wear OS (API 30+)
